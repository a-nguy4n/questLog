Quest Planner

Under "Construction":

This page would hold and organize the user's list of tasks they need to complete. Users would be able to add as many tasks as they want, set a due date, categorize their tasks, set a priority level, and have the point value be calculated. Also, users can create their own "Quest Type" or filter that would show specific types of tasks. For instance, they can create a "random" type and any quest they flag as "random" will appear when they specifically filter quests that are "random".
