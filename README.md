
I decided to used and createCustom HTML Components because my website relies on multiple interactive widgets. For instance the Focus Timer, Quest Planner, Friends List Widget, and Well-Being Tracker. Each widget will require their own internal structure, styling, and JavaScript behavior. With plain HTML, CSS, and JS, these widgets would need repeated markup and scattered event logic. This makes the code difficult to maintain and expand, especially as I was coding the dashbaord. The Custom Elements allowed me to create each widget in its own self-contained component, keeping its template, styles, and functionality organized and isolated from the rest of the main dash page. This approach made it possible to reuse widgets, keep the code modular, prevent any variable conflicts, and manage each widget’s state cleanly. As such, using the Web Components was necessary to meet my goal of creating a structured and more scalable dashboard without too much confusion or sorting through the code.
